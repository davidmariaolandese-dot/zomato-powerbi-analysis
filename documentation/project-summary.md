# Project Summary

## Business Context

The project focuses on analyzing Zomato restaurant data to support business decision-making through Power BI reporting.

## Main Analysis Areas

- Restaurant distribution
- Customer ratings
- Country and city performance
- Cuisine analysis
- Price range analysis

## Data Preparation

The dataset was imported into Power BI and cleaned using Power Query. The preparation phase included data type correction, column formatting, and basic transformation steps needed for reporting.

## Dashboard Design

The dashboard was designed to provide a clear overview of key restaurant performance indicators and allow users to explore the data interactively.

## Key Learnings

This project strengthened my skills in Power BI, Power Query, DAX, data modeling, and business-oriented dashboard design.
